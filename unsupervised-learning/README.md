# Unsupervised Learning

These projects use K-means to find structure in unlabelled feature spaces.

| Project | Data | Focus |
|---|---|---|
| [Handwritten digit clustering](k-means/) | 8×8 digit images | Inertia, centroids, and interpretation of arbitrary cluster labels |
| [Masculinity survey analysis](cumulative-project/) | Survey responses | Encoding ordinal answers, profiling clusters, and cautious interpretation |

The projects contrast a compact image dataset with a socially complex survey, highlighting why cluster interpretation depends heavily on preprocessing and domain context.
