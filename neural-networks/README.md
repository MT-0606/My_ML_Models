# Neural Networks

These projects use PyTorch for a continuous regression task and categorical prediction.

| Project | Task | Network |
|---|---|---|
| [Residential EV charging loads](intro-to-pytorch-neural-networks/) | Predict charging energy in kWh | Feed-forward regression network with MSE loss |
| [Hotel cancellations](pytorch-for-classification/) | Predict cancellation and reservation status | Binary and multiclass feed-forward classifiers |

Both notebooks cover tensor preparation, network construction, loss functions, optimisers, training loops, and held-out evaluation. Their project READMEs distinguish recorded outputs from instructional reference values and identify reproducibility issues that remain to be fixed.
