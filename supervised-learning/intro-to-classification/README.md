# Introduction to Classification

Two notebook projects introduce tree-based classification and the difference between a single interpretable tree and an ensemble of many trees.

| Project | Model | Main lesson |
|---|---|---|
| [Identifying flags](decision-trees/) | Decision tree | Tree depth controls model complexity and generalisation |
| [Predicting income](random-forests/) | Random forest | Ensemble models support nonlinear feature interactions, but extra features may add little value |

Both projects use train/test splits and recorded accuracy. Their individual READMEs describe the datasets, results, limitations, and local setup.
