# Dataset

The complete JSON datasets are stored as GitHub Release assets because several files exceed GitHub's normal repository file-size limit.

First, download the following files from the repository's **Yelp Datasets** release:
* `yelp_business.json`
* `yelp_checkin.json`
* `yelp_data.json`
* `yelp_photo.json`
* `yelp_review.json`
* `yelp_tip.json`
* `yelp_user.json`

Then, place them in this directory before running the notebooks.
