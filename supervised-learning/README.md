# Supervised Learning

This section collects projects in which labelled examples are used to learn predictions. It progresses from a one-feature regression model through tree ensembles, text classification, nonlinear support-vector boundaries, and cumulative projects with larger datasets.

## Projects

| Group | Project | Main technique |
|---|---|---|
| Regression | [US honey production](linear-regression/) | Simple linear regression and extrapolation |
| Introductory classification | [Flag identification](intro-to-classification/decision-trees/) | Decision trees and depth control |
| Introductory classification | [Income prediction](intro-to-classification/random-forests/) | Random forests and feature comparisons |
| Advanced classification | [Email similarity](advanced-classification/naive-bayes/) | Bag-of-words and multinomial Naive Bayes |
| Advanced classification | [Baseball strike zones](advanced-classification/support-vector-machines/) | RBF support-vector machines |
| Cumulative classification | [Tweet investigations](cumulative-project/) | KNN, Naive Bayes, and logistic regression |
| Cumulative regression | [Yelp rating prediction](regression-cumulative-project/) | Multiple linear regression and feature subsets |

Each project README reports the notebook's recorded results, clarifies whether evaluation is held out, and identifies limitations or useful next steps.
